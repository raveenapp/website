- The theme was based off [petrapixel's layout generator](https://petrapixel.neocities.org). They have great resources for webdesign!
- I used the static site generator [Hugo](https://gohugo.io/) 
- I did used alot of the same Hugo code from the [smol theme](https://github.com/colorchestra/smol). Credit to them for the
- I got the header and footer banner from [Free Game Assets on itch.io](https://free-game-assets.itch.io/free-summer-pixel-art-backgrounds)
- Visitor counter: [websiteout](https://www.websiteout.ca/counter.php)
- The guestbook: [htmlcommentbox](https://www.htmlcommentbox.com)
- Great tool for generating colour palettes: [paletton](https://paletton.com/)
- I did use some AI assistance with trouble shooting errors but nothing in this site was "vibe-coded"
